# ผลการตรวจสอบ — 3 พฤศจิกายน 2026

## Automated tests

รัน `node --test tests/core.test.cjs` ผ่าน 17 ชุด โดยไม่ติดตั้ง dependency เพิ่ม (ปรับตามระบบความสามารถและ cap ใหม่)

- ข้อมูลเริ่มต้นถูกต้อง มี A/B และบอส โดย template ไม่ถูกลงทะเบียน
- บอสซ่อนเมื่อปิด เปิดแล้วเรียกใช้ระบบต่อสู้ได้
- cap รายค่า ค่าติดลบ และทศนิยม พร้อมลดตามสัดส่วนเมื่อเกินงบ 100 แสดงคำเตือนโดยไม่แก้ต้นฉบับ ค่าที่ไม่ใช่ตัวเลข/ไม่จำกัดยังถูกปฏิเสธ
- ปฏิเสธ ID ซ้ำ ชื่อว่าง และต่อสู้กับตัวเอง
- SPD กำหนดลำดับเริ่ม สุ่มเมื่อเท่ากัน และบันทึกการหลบได้
- ATK/DEF/HP ส่งผลต่อการต่อสู้ และเสมอเมื่อครบ 100 ตาโดยยังไม่มีผู้ชนะ
- จำลอง 10,816 คู่จากชุดแต้มขอบเขตและชุดแต้มที่สร้างด้วย seed คงที่ ตรวจ HP ผู้ชนะ ขีดจำกัดตา และข้อมูลต้นฉบับไม่ถูกแก้
- ไฟล์ script และรูปเริ่มต้นมีอยู่จริง ลำดับโหลดถูกต้อง
- ไฟล์เก่าที่มี 4 stats ยังใช้ได้ สกิลและติดตัวไม่รู้จักถูกปฏิเสธ
- สกิลทั้ง 4 ทำงานทุก 3 ตาของตัวเอง ทดสอบ poison, heal และ shield ตามกติกา
- คริติคอล เจาะเกราะ ดูดเลือด และติดตัวทั้ง 3 ส่งผลจริง โดยไม่ให้ HP หรือโล่เกินเพดาน
- ทดสอบสกิล/ติดตัว 256 คู่ ค่าสถานะไม่หลุดขอบเขตและสู้ใหม่ไม่มีสถานะค้าง
- หลบรวมโบนัส SPD ไม่เกิน 20% หนามฆ่าพร้อมกันให้เสมอ พิษที่ฆ่าแล้วไม่ให้ฮีลกลับมา

## ตรวจในเบราว์เซอร์จริง

ตรวจผ่าน HTTP preview ที่จำกัดเฉพาะโฟลเดอร์โปรเจกต์บน localhost:

- แสดงมอนสเตอร์เริ่มต้นสองตัว รูปโหลดครบ และบอสซ่อน
- เริ่มต่อสู้แล้ว HP/บันทึกเปลี่ยน จบแล้วแสดงผู้ชนะและ HP ฝ่ายแพ้เป็น 0
- สู้ใหม่ ดูผลทันที ล้างสนาม และยกเลิกระหว่างต่อสู้ใช้งานได้
- เลือกตัวเดียวกันแสดงคำเตือนและปิดปุ่มเริ่ม
- ทดลองใส่ 999 ในทั้ง 8 stats แล้วรีเฟรช: หน้าเว็บแสดงค่าที่ cap รวม 100 พร้อมเหตุผล และ HP ในสนามคิดจากค่าที่ cap จริง ต่อสู้จนจบได้
- ทดลองรูปที่ไม่มีจริง: โหลด placeholder สำเร็จ
- ทดลอง `enabled: true` ในไฟล์บอสแล้วรีเฟรช: แสดงบอส เลือกได้ และต่อสู้จนจบได้
- ตรวจหน้าจอเดสก์ท็อปและมือถือ 390px รวมชื่อภาษาไทยยาว 230 ตัวอักษรและคำอธิบายยาว ไม่มีการล้นแนวนอน
- ตรวจ Console หลังคืนข้อมูลเริ่มต้นและโหลดใหม่ ไม่พบ error
- สกิล พิษ คริติคอล ดูดเลือด และฟื้นตัวปรากฏในบันทึกจริง สู้ใหม่และล้างสนามล้างสถานะได้
- เปิดคู่มือเพดานและความสามารถบนมือถือ 390px ได้ ไม่มีการล้นแนวนอน

คืนไฟล์หลังทดลอง cap แล้ว: A มี 100 แต้มพร้อม strike/berserk, B มี 100 แต้มพร้อม poison/regeneration, บอส `enabled: false` พร้อม shield/thorns

## ข้อจำกัดการตรวจสอบ

- เบราว์เซอร์อัตโนมัติไม่อนุญาต protocol `file://` จึงไม่ได้ทดสอบการดับเบิลคลิกเปิดไฟล์โดยตรงในเบราว์เซอร์นั้น ตรวจผ่าน HTTP แทน โค้ดใช้ script tags และไฟล์ภายใน ไม่มี fetch, module imports หรือ API ที่ต้องพึ่ง server
- ไม่ได้ทำ PR หรือ Merge บน GitHub จริง ขั้นตอนใน README เตรียมไว้ให้ผู้จัดและผู้เรียนทำใน repository ของตนเอง
- ไม่ได้ทดสอบครบทุกเบราว์เซอร์หรืออุปกรณ์จริง
